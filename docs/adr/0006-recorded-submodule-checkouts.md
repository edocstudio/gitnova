# ADR 0006: Reliable context and recorded submodule checkouts

Accepted, 2026-10-25. Deliver the audit corrections first, then recursive discovery and one reviewed submodule operation at a time.

Diff selection uses raw Git path bytes rather than presentation strings. Decode C quoting/octal escapes and keep path identity separate from display. Normalize Git's patch prefixes, quote synthesized untracked headers and never silently select another file if matching fails. Unmatched staged paths disable commit confirmation. Refresh retains the cached graph when refs are unchanged; changed refs rebuild a bounded range and re-anchor the visible commit. Missing anchors are explained. Repository-scoped operation feedback outlives inspector navigation.

Submodule relations carry a stable ID derived from the containing repository/worktree identity and relative path, an explicit parent relation, containing and child repository/worktree IDs, root-relative navigation path and parent-relative operation path. Discover initialized descendants with cycle/depth/count limits. Assign repository identities without adding implicit workspace memberships. Workspaces remain independent of Git submodule relationships.

Reuse the existing related-repositories area in the workspace picker for submodule state, open, initialize and restore preview/confirmation. No dashboard, sidebar or new dialog is needed: the related item already identifies the affected child repository. Discovery is read-only with respect to Git; new stable identities can be saved in the app catalog. Mutation preview reads never run hooks, filters, custom update commands or network operations.

“Restore recorded version” means the containing repository's current INDEX gitlink, with HEAD/index/checkout all shown. It is separate from moving to a newer remote revision, which this increment does not implement. Restore checks out the reviewed immutable OID without fetching, forcing, staging the parent or recursing into children. Refuse dirty/hidden-index/active-operation states and detached commits not retained by local branches. Git's no-overwrite-ignore and nonrecursive switch protect the child's files. Coordinate parent and child operations and protect the parent index during the operation; revalidate snapshots and postconditions.

Initialize uses native Git's explicit `submodule update --init --checkout` for the selected path only, with restricted standard transports, bounded execution and no force/remote/recursive update. Native Git resolves relative URLs. It may write submodule registration/config and download objects. Block nonempty destination directories and preexisting cached module metadata that cannot be safely reviewed as an initialized checkout. A failure may leave metadata or downloaded objects and is reported as partial/unknown; no automatic rollback or retry. Subsequent discovery determines the actual resulting state. Initialize nested children as separately previewed operations after their parent exists.

Configured hooks/filters can run during actual checkout; preview neutralizes them. Parent and child index/ref state must be reinspected; batches are not atomic. Tests mutate only temporary repositories and local remotes, covering index-vs-HEAD recorded pointers, dirty/ignored content, detached unpublished commits, nested discovery, custom update command refusal, stale previews, locks and failure recovery.

Reference: [official git-submodule update documentation](https://git-scm.com/docs/git-submodule).

Module admin locations are resolved with native `git rev-parse --git-path`, including per-worktree module directories, rather than assuming the common directory. Canonical ancestor resolution handles not-yet-created directories while enforcing the registered Git directory boundary. See [Git path resolution](https://git-scm.com/docs/git-rev-parse).

Parent status can inspect child working files, so neutralizing only the parent's filter configuration is insufficient. Before status and working-tree patch reads, collect filter driver names from initialized descendants through config/index-only reads and disable those drivers for the resulting native Git invocation. Traversal refuses symlinked gitlinks and fails closed beyond 256 children or 16 levels. Patch commands explicitly request short submodule output; offline reads disallow all transport protocols, including per-protocol overrides.
