# ADR 0027 — Clone into the existing workspace picker

The graph cannot clone an absent repository: it has no commit/ref context yet. Add Clone as an alternative to Add existing in the existing workspace picker and empty-workspace form. Reuse that area for source, destination, review, loading and result. No new screen, sidebar, dashboard or global navigation. Successful registration selects the cloned repository in the requested workspace and opens its real graph.

Preview is local and does not contact the source, run hooks, initialize submodules or create a destination. Confirm pins the source, canonical absent destination, parent identity and workspace identity. Revalidate immediately before reserving the destination with exclusive directory creation. Refuse existing paths, including empty folders and symlinks. A changed preview cannot start. Clone uses standard Git transports and configured credentials/SSH, no shell, recursive submodules, local hardlinks or source hooks/templates. Reject credentials/query strings embedded in a URL and unknown transport helpers. Initial checkout may use configured Git filters; disclose this in the review.

Run one clone command with bounded captured output, one pack/index thread and a ten-minute process-group timeout. Progress stays indeterminate when total transfer work is unknown. On failure, retain partial data and give the exact location and inspection guidance. Never automatically clean or retry a destination. Save a bounded durable attempt journal outside membership receipts so interruption before registration remains discoverable from the Clone area after restart. Catalog registration targets the reviewed workspace even if the active workspace changes during cloning; clone and registration are separate effects.

This is the first feature-completion slice of the user's requested priority: missing features first, then long-session performance/RAM measurement, then broader real-use defects and recovery. The latter two workstreams are not claimed complete by clone fixtures or short process measurements.
