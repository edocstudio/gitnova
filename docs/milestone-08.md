# Milestone 08 — Audit corrections

Resolves F1–F3 in the [2026-10-25 review](audits/2026-10-25-review.md).

- Git patch paths now decode C quoting, octal bytes and marker separators without trimming actual filename whitespace. Raw Unix byte identity distinguishes paths even if their lossy labels are identical. Hunk text cannot replace file headers. Git adapter patch prefixes are explicit; synthesized untracked headers quote raw path bytes. Missing or ambiguous matches show no unrelated file and prevent commit approval when a staged path cannot be matched.
- Refresh retains the cached window/cursor/scroll when refs are unchanged. Changed refs rebuild a bounded range (up to 1,000 rows) and re-anchor the visible commit. History explicitly reapplies the reconciled scroll position. If a previous anchor is outside the bounded rebuilt range, a contextual notice explains the fallback rather than silently pretending the position was restored.
- Operation feedback is kept per membership in App, surviving working-inspector navigation. Pending state remains visible, failures use the existing dismissible error surface and results persist when returning to Working changes. Other mutation entry points are disabled while a write is pending. Background snapshots started before a write cannot overwrite its newer state.

Regression coverage uses actual staged names with spaces, trailing whitespace, quotes, tabs, newlines and Thai. Byte-preserving invalid-UTF-8 identities are unit tested; filesystem fixtures for those bytes run only on Linux because macOS rejects such filenames. Browser coverage also restores older loaded pages after refresh/repository switching, re-anchors after an external new head and observes a delayed failing commit hook after leaving the inspector. Parent/child safety tokens and existing reviewed writes remain in force.

Validation on macOS, 2026-10-25: format check and strict workspace/all-target Clippy passed; all 64 Rust tests, 13 frontend tests and the production build passed. All 13 real-core browser workflows passed in 4.3 minutes, including the three audit regressions. Browser transport is emulated while Git results come from the real Rust core and temporary repositories; native webview automation and other operating systems remain unverified. The test linker emits macOS deployment-target warnings from the installed Rust toolchain; this run does not establish release packaging compatibility.
