# Version 1.0.0 preparation

The owner selected 1.0.0 for distribution and subsequent user testing on
2026-11-07. This replaces the current 0.1.0/alpha product label; historical
verification reports retain their original versions and results.

## Changes

- All 12 workspace packages, the desktop npm package/lockfile and Tauri use
  1.0.0. The header reads its version from the desktop package manifest.
- Release assembly produces versioned release-candidate notes. Draft upload
  accepts an exact matching stable tag such as `v1.0.0`, alongside the legacy
  alpha-tag route. Both routes remain draft-only and verify artifact bytes and
  the existing tag's source commit. No tag is created or moved by this change.
- Native artifact upload/download names agree across the reusable CI and release
  workflow. Internal legacy evidence names remain compatible.
- Current status documentation reflects 1.0.0 and unsigned installer limitations.
  No dependency versions, license terms or legal-approval flags were changed.
